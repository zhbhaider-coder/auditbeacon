# AuditBeacon — Free SEO, AEO & GEO Page Auditor

Paste any URL and get 52 checks across 13 categories with clear fix guidance. No account needed, no signup, runs entirely in the browser.

**Live site:** https://auditbeacon.pages.dev/

## What it does

- **52 checks** across 13 categories: meta tags, headings, images, links, structured data (JSON-LD), Open Graph, Twitter cards, performance hints, accessibility, mobile-friendliness and more
- **A–F grade** with actionable fix guidance for every failed check
- **SEO / AEO / GEO scoring** — see how your page performs for search engines, answer engines, and generative AI
- **Client-side only** — your URL is fetched and analyzed in your browser; nothing is stored on a server

## How to use

1. Open https://auditbeacon.pages.dev/
2. Paste any page URL
3. Get your grade + full checklist of fixes

## Tech

Static site (HTML/CSS/JS) + Cloudflare Pages Function for the audit API. MIT licensed.
